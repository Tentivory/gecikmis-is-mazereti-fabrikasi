# Gecikmiş İş Mazereti Fabrikası 🏭

**Dikkat! Bu repo son derece ciddi bir bilimsel çalışmanın ürünüdür.** (Değildir.)

Bu proje, insanlığın en büyük sorunlarından biri olan "işe gecikme" problemini çözmek için geliştirilmiştir. Artık patronunuza, hocanıza veya sevgilinize "trafikte kaldım" demek zorunda değilsiniz. Bilimsel olarak kanıtlanmış (asla) mazeretler üretebilirsiniz!

## Nasıl Çalışır?

1. Python 3.x kurun (eğer yoksa, mazeret olarak "Python kurmaya çalışırken zaman kaybettim" diyebilirsiniz).
2. `python mazeret_fabrikasi.py` komutunu çalıştırın.
3. Kategori seçin.
4. Üretilen mazereti kopyalayın ve gönderin.
5. İşinize devam etmeyin, çünkü zaten geciktiniz.

## Özellikler

- Tamamen Türkçe mazeretler
- Abartılı ve absürt içerik
- Gerçekten çalışır (test edildi, 0.0001 saniyede)
- Hiçbir işe yaramaz ama eğlencelidir
- Gizli bir şey içerir (bulamazsınız)

## Katkıda Bulunma

Pull request açmayın, zaten gecikir. Issue açmayın, mazeret üretir.
